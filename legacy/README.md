# Legacy

These are archived sources. They are not built or shipped.

- `auratab/` is AuraTab 1.0.0, the New Tab override that Atelier Launchpad replaced in 2.0.0. It includes its design-system doc, tests, store listing and screenshots, and the icon and screenshot scripts. Its paths assume it sat at the project root, so it won't build from here as-is.
- `atelier-launchpad-prototype/` is the original standalone launchpad, before it was promoted to the project root.
