## Detailed description (EN)

```
AuraTab turns every New Tab into a clean, one-click launchpad for the sites you actually use.

• Most visited: your top sites, ranked by your real browsing, appear as large tiles automatically.
• Bookmarks dashboard: every bookmark folder becomes a tidy card. There's nothing to organise twice, and edits you make in the browser show up instantly.
• Instant search: press / and type to filter everything. Enter opens the first match, or searches the web if nothing matches.
• Your way: light, dark or system theme; comfortable or compact density; collapsible folders; hide sites you don't want to see.
• Fast: no frameworks and no network calls, and the page paints instantly from a local cache.
• Private by design: everything runs on your device. AuraTab has no servers, no analytics and no tracking, and its security policy blocks all network requests.

Available in English and Thai.
```

## Single purpose (Chrome "Privacy practices" tab)

```
AuraTab replaces the New Tab page with a dashboard that shows the user's most visited sites and bookmarks for one-click access.
```

## Permission justifications

| Permission | Justification |
| --- | --- |
| `topSites` | Displays the user's most visited sites as tiles on the New Tab page. |
| `bookmarks` | Displays the user's bookmarks, grouped by folder, on the New Tab page, and refreshes when bookmarks change. Read-only. |
| `favicon` | Shows each site's icon from the browser's local favicon cache, without any network request. |
| `storage` | Stores the user's settings, hidden sites, and local open counts on the device. |
| `search` | When the user presses Enter on a search with no matching site, sends the text to the browser's default search engine. |
| New Tab override | The extension's single purpose is a New Tab dashboard. |
| Remote code | **No.** All code is packaged in the extension. |

## Data usage disclosure (Chrome)

- Data collected: **Web history** (most visited sites are read locally for display only). Nothing else.
- Tick all three certifications: not sold to third parties; not used for unrelated purposes; not used for creditworthiness or lending.
